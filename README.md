Walmart Weekly Sales Forecasting & Analysis
This project performs exploratory data analysis (EDA), feature engineering, time-series forecasting, and model evaluation on historical Walmart sales data. It compares multiple machine learning algorithms—including Linear Regression, Random Forest, and XGBoost—to predict future weekly sales based on historical trends and macroeconomic variables.

📌 Project Overview
Accurate sales forecasting helps retail organizations optimize inventory management, supply chain logistics, and resource allocation. This pipeline processes store-level sales data to:

Identify seasonal trends and overall sales performance across stores.

Analyze the impact of economic factors (CPI, Fuel Price, Unemployment, Temperature) and holidays on sales.

Feature-engineer lag variables and rolling statistics to capture time-series dependencies.

Train and compare multiple predictive models using a time-based train-test split.

Generate an autoregressive multi-week sales forecast.

📊 Dataset Structure
The project expects a dataset named Walmart.csv containing the following primary fields:

Store: Store identifier number.

Date: Date of the sales week.

Weekly_Sales: Total sales for the given store and week.

Holiday_Flag: Binary indicator (1 = Holiday week, 0 = Non-holiday week).

Temperature: Average temperature in the region.

Fuel_Price: Cost of fuel in the region.

CPI: Consumer Price Index.

Unemployment: Unemployment rate in the region.

🛠️ Workflow & Methodology
The pipeline executes through the following stages:

1. Data Ingestion & Preprocessing
Parses dates (dayfirst=True) and sorts the dataset chronologically.

Checks dataset dimensions and initial records.

2. Exploratory Data Analysis (EDA)
Overall Sales Trend: Line chart tracking total network-wide weekly sales over time.

Store Performance: Bar chart comparing aggregate lifetime sales across store IDs.

Holiday Impact: Analysis comparing average weekly sales during holiday vs. non-holiday weeks.

Monthly Seasonality: Line plot mapping average weekly sales by month to identify peak shopping seasons.

3. Feature Engineering
Constructs historical features per store to assist time-series modeling:

lag_1: Sales from 1 week prior.

lag_4: Sales from 4 weeks prior (~1 month lag).

lag_12: Sales from 12 weeks prior (~1 quarter lag).

rolling_mean_4: 4-week moving average of sales.

Null values generated by shifting/rolling windows are dropped.

4. Correlation Analysis
Generates a Heatmap evaluating Pearson correlation between Weekly_Sales and economic indicators (Temperature, Fuel_Price, CPI, Unemployment).

5. Model Training & Evaluation
Train-Test Split: Employs a time-based 80/20 split (preserving chronological order) rather than random sampling.

Evaluation Metric: Mean Absolute Error (MAE).

Algorithms Evaluated:

Linear Regression: Baseline linear model.

Random Forest Regressor: Ensemble tree-based model (200 estimators). Includes feature importance extraction.

XGBoost Regressor: Gradient-boosted decision trees (600 estimators, learning rate = 0.03, max depth = 4).

6. Recursive Forecasting
Generates a 12-week future forecast using an autoregressive loop with the trained Random Forest model, updating lag features iteratively.

🚀 Getting Started
Prerequisites
Ensure you have Python 3.8+ installed along with the required libraries:

Bash
pip install pandas matplotlib seaborn scikit-learn xgboost
Running the Analysis
Clone or download this repository.

Place your Walmart.csv file in the root directory.

Execute the script or notebook:

Bash
python Walmart_Sales_Forecasting.py
